CATALOG / LOCAL AI INSTALL

업무에 맞는 AI만,
고객 환경 안에 설치합니다.

Core Company는 하나의 거대 모델을 모든 업무에 적용하지 않습니다. 문서, 이미지, 음성, 자동화 업무에 맞는 로컬 AI 모듈을 고객의 인트라넷과 온프레미스 환경에 맞춰 구성합니다.

외부 API 전송 없이 구성고객 환경 내 설치·운영업무별 선택형 모듈

표기된 모델·도구는 설치 예시 또는 후보입니다. 최종 모델, 라이선스, 자원 구성은 고객 환경과 검증 범위를 확인한 뒤 확정합니다.

04 / OnPress OS & architecture

구성은 하나로 정하지 않고,
환경에 맞춰 선택합니다.

OnPress OS는 공간 통합을 위한 선택지입니다. 데이터 등급, 연결성, 사용량, 지연 허용치, 운영 인력과 예산을 함께 검토해 온프레미스·클라우드·하이브리드 구성을 설계합니다.

SOURCE 공간의 데이터와 신호
→
CONTEXT 문서·설비·센서·업무 기록
REASON RAG: 최신 문서와 근거 탐색
→
FORMAT 파인튜닝: 안정적 반복 업무와 형식

장비·전력·운영·유지보수 비용과 현장 적합성은 PoC와 견적으로 검토합니다. 특정 모델의 성능이나 비용 구조를 단정하지 않습니다.

05 / PoC & decision

성과를 약속하기보다,
판단 기준을 먼저 만듭니다.

PoC는 한 공정 또는 한 업무에 한정합니다. 공간별로 다른 운영 목적을 기준선과 비교할 수 있도록 시작 전에 합의합니다.

도입 진단 문의
범위

대상 공간, 공정 또는 업무, 연결 데이터와 제외 범위를 문서화합니다.

책임

고객과 수행 주체의 역할, 승인과 안전 책임을 사전에 검토합니다.

성공 기준

생산성·품질·안전·에너지·서비스 운영 중 고객이 선택한 기준을 비교합니다.

결과

성과와 확장 여부는 PoC 종료 후 고객별 결과로 판단합니다.

PoC 기간, 비용, 데이터 접근, 결과의 활용 범위는 공간 진단과 계약 협의 후 개별 확정합니다.

07 / FAQ

도입 전에 확인할 질문

어떤 공간에 적용할 수 있나요?

제조 현장, 오피스, 숙박·민박, 주거, 스마트팜 등 공간별 조건과 운영 목적을 진단한 뒤 적합성을 검토합니다.

온프레미스와 클라우드는 어떻게 선택하나요?

데이터 등급, 연결성, 사용량, 지연 허용치, 운영 인력과 예산을 함께 검토해 적합한 구성을 제안합니다.

비용은 어떻게 산정하나요?

진단 범위, 연동 대상, 장비, 운영 방식, 유지보수와 계약 구조를 바탕으로 고객별로 검토합니다. 일률 가격이나 개선 효과를 사전에 제시하지 않습니다.

데이터·개인정보·현장 안전은 어떻게 다루나요?

데이터 흐름과 접근 권한, 개인정보 처리 필요성, 현장 안전 책임을 PoC 범위와 계약 협의 단계에서 확인합니다.
