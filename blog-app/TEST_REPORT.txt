6. Pagefind 한글 검색

review build에서 한글 게시글 검색어가 결과를 반환하는 E2E가 통과했습니다. 결과 제목, summary/excerpt, category, 수정일, 읽기 시간을 렌더링하고 결과 없음 상태의 role=status와 카테고리 링크를 검사했습니다.

경고: Pagefind 1.5.2는 한국어 stemming을 지원하지 않습니다. 정확한 단어 검색은 정상이나 어근 변화에 따른 확장 검색은 제공하지 않습니다.

production에는 sample:false 공개 글이 0개입니다. 빌드 안정성을 위해 내부 빈 색인 번들은 존재하지만 임시 HTML은 제거되고 내부 센티널 결과는 UI에서 제외됩니다.

10. 실패와 경고 이력

최종 결과에 남은 테스트 실패는 없습니다.

중간에 Lighthouse CI의 Windows 임시 Chrome 폴더 정리 EPERM 오류가 있어 공식 Lighthouse 패키지를 유지한 채 로컬 Chromium remote debugging 실행 스크립트로 교체했습니다. 교체 후 실제 audit와 threshold 검사가 성공했습니다.

중간 type check에서 테스트 파일의 불필요한 @ts-expect-error 1건이 발견되어 제거했습니다. 수정 후 check 0 errors와 전체 회귀 검사를 재실행했습니다.

11. 자동 검사 범위 밖 주의사항

실제 운영 네트워크, Cloudflare Pages 결합, DNS, 캐시, Web Analytics는 로컬 범위 밖이며 Hermes가 배포 후 확인해야 합니다. 운영 배포와 외부 설정 변경은 수행하지 않았습니다.
