5. 분석

사이트 자체는 토큰이나 Measurement ID를 포함하지 않습니다.
공통 브리지는 window.gtag가 있으면 gtag를 사용하고, 없으면 기존 window.dataLayer 배열을 사용합니다.
둘 다 없으면 조용히 종료합니다.

허용 이벤트 데이터는 article slug, category slug, CTA 종류, 위치, 결과 수 같은 비식별 값입니다.
검색어 원문과 자유 입력 텍스트는 전달하지 않습니다.

Cloudflare Web Analytics 또는 GA 로더 활성화는 Hermes의 배포 단계 책임입니다.

6. 환경 변수

필수 환경 변수: 없음

INCLUDE_SAMPLES와 REVIEW_BUILD는 npm 스크립트가 로컬 검수 빌드에서만 설정합니다.
운영 빌드에서 수동으로 true를 지정하지 마십시오.

7. 설치 참고

현재 검수 환경은 Node 26.5.1, npm 12.0.2였습니다.
package.json 엔진 범위는 >=24 <27이며, 배포 기준은 Node 24 LTS입니다.
Hermes는 Node 24의 깨끗한 환경에서 npm ci와 전체 검증을 다시 실행해야 합니다.

npm install 중 npm 12가 esbuild@0.28.1 postinstall 차단 경고를 1건 표시했지만,
현재 설치에서는 check/build/Pagefind/Playwright/Lighthouse가 모두 성공했습니다.
깨끗한 Node 24 환경에서 동일 경고가 빌드를 막는지 확인하고 조직의 install-script 정책에 따라 처리하십시오.
